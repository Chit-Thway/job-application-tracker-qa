# Job Application Tracker — QA Portfolio

This repository is a public, sanitized record of defects found while manually testing the [Job Application Tracker](https://myjobtracker.com.au/).

It demonstrates practical QA work: reproducing real user-facing problems, comparing expected and actual behaviour, assessing impact, documenting fixes, and recording regression coverage.

## Bug reports

The portfolio currently contains **10 fixed defects** covering data extraction, browser-extension compatibility, networking, responsive design, encoding, and data quality.

➡️ **[Open the reported bugs directory](reported-bugs/README.md)** to browse the numbered report index and detailed reproduction records.

Each bug folder contains one focused report with:

- environment and preconditions;
- repeatable steps to reproduce;
- expected and actual results;
- severity, priority, and user impact;
- resolution and regression evidence;
- screenshots when suitable sanitized evidence is available.
